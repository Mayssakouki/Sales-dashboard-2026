# Sales Performance Dashboard 2026

## 📋 Project Overview

This dashboard provides a comprehensive and interactive view of sales activities .

## 🗄️ Data Model

- **Orders** table  
- **Customers** table

## 🧹 Data Preparation & Transformation

- Data cleaning and quality improvement using **Power Query**
- Used **DAX COALESCE** function to replace empty values with 0
- Optimized data types across columns
- Merged 2 columns " first_name" et "last_name" to get a one column named customer_name
- Established proper relationships in the data model

## ✨ Key Features

- Fully interactive dashboard with dynamic filtering
- Optimized layouts for **Desktop** and **Mobile** views
- Professional and modern UI/UX design
- Real-time slicing and filtering capabilities

## 📊 Visualizations

- Bar Charts and Column Charts
- Donut Charts
- KPI Cards
- Interactive Slicers
- Trend analysis visuals

## 🛠️ Technologies & Skills Demonstrated

- **Power BI Desktop**
- **Power BI Service** (Publication & Sharing)
- **DAX** (Data Analysis Expressions)
- **Power Query** (ETL processes)
- Data Modeling & Relationship Management
- Responsive Dashboard Design (Desktop + Mobile)

## 🚀 Deployment

The dashboard has been published to **Power BI Service** for online access and sharing.
